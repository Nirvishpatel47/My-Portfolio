The Purpose

Generic AI chat widgets frequently hallucinate answers or invent policies because they lack strict grounding in actual company documentation. When customers experience issues, standard chatbots frustrate them with repetitive loops instead of routing the problem to a human operator.

I built AssistFlow to solve this specific challenge: a lightweight, self-hostable customer support backend where all answers are strictly constrained to uploaded company documentation and cited with labeled source references, backed by automated escalation logic for frustrated customers.

What I Built

AssistFlow consists of a multi-tenant FastAPI backend, an embeddable JavaScript widget (`widget.js`), and an administrative management API:

  • Multi-Format Document Parser: Specialized parsing for PDFs (PyMuPDF), DOCX files, spreadsheets, and over 25 programming languages with brace-aware chunking.
  • Isolated Vector Retrieval: Vector search via Qdrant utilizing cosine similarity, strictly scoped to each user/tenant ID to prevent cross-account data leaks.
  • Stateful Conversation Engine: Per-visitor conversation states persisted in PostgreSQL (`NEW` → `ACTIVE` → `HANDLING_COMPLAINT` → `EXTRACTING_CONTACT` → `ESCALATED`).
  • Automated Escalation Dispatcher: When a complaint or human request is recognized, the system captures contact information and dispatches a rich email containing the entire conversation transcript to the site administrator.
